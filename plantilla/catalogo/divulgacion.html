01 — La idea

Descartar la mitad en cada paso

Buscar un valor en un arreglo desordenado obliga a mirar los elementos uno por uno. Si el arreglo está ordenado, se puede hacer algo mucho mejor: mirar el elemento del medio y descartar de un golpe la mitad que no puede contener lo buscado .

Dado un arreglo ordenado \(A[0..n-1]\) y un valor \(x\), la búsqueda binaria mantiene un intervalo \([izq, der]\) que contiene a \(x\) si \(x\) está en \(A\), y lo reduce a la mitad en cada iteración.

Cada comparación elimina la mitad de lo que queda.

02 — El algoritmo

Probalo con tus propios datos

Avanzá con Paso o dejalo correr con Reproducir. La entrada es el valor buscado, luego dos puntos y el arreglo; si el arreglo no está ordenado, se ordena antes de empezar.

Los interactivos pueden salirse de la columna de texto con la clase ancho. En el celular vuelven a ocupar el ancho de la pantalla.

03 — El costo

¿Cuántas comparaciones hacen falta?

La búsqueda binaria en un arreglo de \(n\) elementos hace a lo sumo \(\lfloor \log_2 n \rfloor + 1\) comparaciones.

Después de cada comparación fallida, el intervalo tiene a lo sumo la mitad de los elementos que tenía.

Tras \(k\) comparaciones quedan a lo sumo \(n / 2^k\) elementos. El proceso termina cuando ese número es menor que 1, es decir, cuando \(k > \log_2 n\).

La diferencia con la búsqueda lineal crece muy rápido. Movelo vos:

04 — En código

Una implementación en Python


    def busqueda_binaria(a, x):
        izq, der = 0, len(a) - 1
        while izq <= der:
            medio = (izq + der) // 2
            if a[medio] == x:
                return medio
            if a[medio] < x:
                izq = medio + 1
            else:
                der = medio - 1
        return -1

En lenguajes con enteros de tamaño fijo, (izq + der) // 2 puede desbordarse. La forma segura es izq + (der - izq) // 2.

La versión de arriba: un ciclo y dos índices. Usa memoria constante.

Se llama a sí misma sobre la mitad que queda. Es más cercana a la definición, pero usa \(O(\log n)\) de pila.

En Python, el módulo bisect ya la trae: bisect.bisect_left(a, x).

05 — Repaso

Comprobá lo que entendiste

¿Qué condición debe cumplir el arreglo para poder usar búsqueda binaria?

  • Tener una cantidad par de elementos
  • Estar ordenado
  • No tener elementos repetidos

Solo si está ordenado se puede saber, mirando el elemento del medio, en qué mitad seguir buscando.

¿Cuál es el costo de la búsqueda binaria?
\(O(\log n)\) comparaciones.
¿Qué invariante mantiene el ciclo?
Si \(x\) está en el arreglo, está entre \(izq\) y \(der\).
¿Cuándo termina sin encontrar el valor?
Cuando \(izq > der\): el intervalo quedó vacío.
Ejercicio: ¿cómo encontrar la primera aparición de un valor repetido?

Al encontrar el valor, no devolver de inmediato: guardar la posición y seguir buscando en la mitad izquierda.

Aunque la idea básica de la búsqueda binaria es comparativamente sencilla, los detalles pueden ser sorprendentemente difíciles.
